Campus Marketplace

A student-to-student buying and selling platform designed for university campuses. Features product listings, a shopping cart, and a simple checkout flow — all built with vanilla HTML, CSS, and JavaScript. Data is persisted using localStorage so sessions feel continuous.

  • Product listing with search and filter
  • Shopping cart with quantity management
  • Responsive grid layout using CSS Grid
  • Local storage for cart persistence

NaijaWeather App

A weather application focused on Nigerian cities. Users search for any city and receive current conditions, a 5-day forecast, humidity, and wind speed — all fetched in real time from the OpenWeatherMap API. The UI adapts colour themes based on weather conditions.

  • Live weather data via REST API
  • Search auto-complete with recent history
  • Dynamic background themes per condition
  • Temperature unit toggle (°C / °F)
🔗 Live Demo ⌥ GitHub

GradeTracker Pro

An academic grade management tool that lets students log courses, enter scores, and automatically calculates their GPA using the Nigerian university 5-point grading scale. Includes a visual chart and semester-by-semester progress tracking.

  • GPA calculator with Nigerian grading scale
  • Course management (add / edit / delete)
  • Bar chart visualization with CSS
  • Export results as printable report
🔗 Live Demo ⌥ GitHub

Memory Card Game

A fun browser-based memory matching card game built entirely with vanilla JavaScript DOM manipulation. Features a flip animation, move counter, timer, three difficulty levels, and a high-score leaderboard stored in localStorage.

  • CSS 3D card flip animations
  • Shuffle algorithm (Fisher-Yates)
  • Timer and move counter
  • High score persistence via localStorage
🔗 Live Demo ⌥ GitHub
